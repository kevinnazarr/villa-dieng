## Summary

Replaced the `/cabin/:propertySlug/:cabinSlug` placeholder with an API-driven detail page: semantic breadcrumb (property → cabin), static editorial gallery (main eager image + up to 3 lazy thumbs, shared image-tolerance rule), header (h1 name, capacity, `formatCurrency` price + per-night), verbatim description, amenity chips, embedded property context strip, and a plain `/booking` CTA. One request per param set; all 404 causes share one localized not-found state; other failures get a localized error + retry.

## API Contract Used

- `GET /api/v1/properties/{propertySlug}/cabins/{cabinSlug}` → `{data: Cabin}` with `images`, `amenities`, and `property` eager-loaded (verified in `CabinController@show` + `CabinResource`). No second property request.
- Failure semantics verified in `CatalogApiTest`: unknown/inactive property, unknown/inactive cabin, and cross-property cabin all → 404 `{message: 'Not Found.'}`; flat `/api/v1/cabins/{slug}` does not exist.
- Shapes consumed 1:1 from existing `types/api.ts`; no type changes.

## Important Technical Decisions

1. **Single request, embedded property** — the detail response already contains `property`; a second fetch would double requests for zero new data.
2. **Shared image helpers** — `CabinCard`'s local `isUsableImageUrl`/`pickPrimaryImage` moved to `lib/images.ts` (+ `sortImages`/`usableImages` for the gallery) so card and detail cannot drift. Only `http(s)://` or `/` paths render; bare storage paths are skipped, never guessed.
3. **Static gallery, no lightbox** — editorial main + thumb row, zero interaction, zero deps; lightbox needs focus-trap/keyboard/motion work disproportionate to MVP.
4. **Status-driven 404 vs error** — `isApiError(err) && err.status === 404` → notFound, else error; missing params short-circuit to notFound without a request.
5. **Dead key removed** — `page.cabinDetail` deleted from both dictionaries once the placeholder was replaced (verified zero references remaining).
6. **CTA is a plain `/booking` link** — the booking route defines no param contract; inventing `?cabin=` would create a fake API.
