# LOG-001 — Docker Development Foundation

- Date: 2026-09-21
- Change type: chore
- Status: complete
- Branch: `feature/docker-foundation`

## Summary

Established a minimal, reproducible local Docker development environment:
PostgreSQL + Redis + Laravel backend + React/Vite frontend via Docker Compose,
with env-based config, healthchecks, persistent PG storage, and the required
PostgreSQL extensions. No business logic implemented.

## Services

| Service  | Image / build            | Host → container | Health          |
|----------|--------------------------|------------------|-----------------|
| postgres | postgres:15-alpine       | 5432 → 5432      | pg_isready      |
| redis    | redis:7-alpine           | 6380 → 6379      | redis-cli ping  |
| backend  | docker/php (php:8.4-cli) | 8001 → 8000      | depends healthy |
| frontend | docker/frontend (node:22-slim) | 5173 → 5173 | depends backend |

## Environment / config changes

- Root `.env` (untracked, gitignored) holds compose ports/credentials; `.env.example` committed.
- Backend container env: `DB_HOST=postgres`, `REDIS_HOST=redis`, cache/queue/session on redis.
- `VITE_API_URL` points at backend host port.
- Host port defaults avoid local conflicts: redis 6380 (host redis on 6379), backend 8001 (portainer on 8000).

## Database / infrastructure changes

- Named volume `pgdata` persists PostgreSQL across recreation.
- Extensions enabled on first volume init: pgcrypto, btree_gist, citext.
- No tables or migrations added.

## Important decisions

- PHP 8.4 image: installed vendor deps require >= 8.4.1 (8.3 fails platform check).
- node:22-slim (glibc) over Alpine: bind-mounted host node_modules has glibc-built rolldown binding, breaks under musl.
- No anonymous node_modules volume: container uses host-installed deps; entrypoint reinstalls only when vite binary missing.
- Redis wired as cache/queue/session for dev parity; availability authority stays PostgreSQL per technical design.

- `init-extensions.sql` runs only on first volume init; reset via `down -v`.

- Frontend is stock Vite template; no booking UI yet (intentionally out of scope).
