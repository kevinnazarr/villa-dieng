## Summary

Replaced the Home placeholder at `/` with the first production-quality public page: typographic forest-900 hero (property name, eyebrow, description, `/booking` CTA), property introduction, cabin grid (`CabinCard`: image-or-placeholder, name, capacity, `formatCurrency` base price + per-night label, cabin-detail link), amenity highlights (union by slug, capped at 6, omitted when empty), and a final booking CTA. Data flows through two sequential reads (`GET /properties` → `GET /properties/{slug}/cabins`) with independent cabin-section degradation. All frontend-authored copy uses `t()`; server content renders verbatim.

## API Contracts Used

- `GET /api/v1/properties` → `{data: Property[]}` (active-only, ordered by name). Empty array → localized empty state, no second request.
- `GET /api/v1/properties/{property:slug}/cabins` → `{data: Cabin[]}` with `images` + `amenities` eager-loaded. Failure after property success → property stays visible + section-level `role="alert"` retry.
- Shapes consumed 1:1 from existing `types/api.ts` (`Property`, `Cabin`, `CabinImage {path, alt_text, sort_order, is_primary}`, `Amenity`, `CollectionEnvelope`); no type changes, no new endpoints.

## Important Technical Decisions

1. **Single-property MVP** — the site renders the available active property without claiming multi-property support; if the API ever returns several, behavior stays deterministic (first row) and the limitation is documented, not designed around.
2. **`t(key, vars?)` minimal interpolation** — simple `{adults}`/`{children}`/`{name}` replacement, unmatched tokens left intact; no pluralization or formatting engine (approved correction).
3. **Image tolerance** — only `http(s)://` or `/`-rooted paths render `<img>`; bare storage paths (e.g. `cabins/x.jpg`) render a forest-100 initial block. No host guessing, no `VITE_API_URL` prefixing, no CDN/storage work. Real image delivery is a backend follow-up.
4. **Static skeleton** — blocks only, no shimmer/animation (approved correction; safe under `prefers-reduced-motion`).
5. **Error chrome localized, server strings verbatim** — page/section errors use `home.*` copy + `common.retry`; `ApiError.message` never becomes primary UI text.
6. **Capacity without pluralization** — `Adults {n} · Children {n}` / `Dewasa {n} · Anak {n}` invariant nouns sidestep EN/ID plural rules with zero engine (found "1 children" in QA, fixed within scope).
6. **Capacity without pluralization** — invariant nouns (`Adults {n} · Children {n}` / `Dewasa {n} · Anak {n}`) sidestep EN/ID plural rules with zero engine (QA caught "1 children", fixed within scope).
7. **Independent degradation** — cabin-section failure preserves property content; property failure is page-level with retry.
